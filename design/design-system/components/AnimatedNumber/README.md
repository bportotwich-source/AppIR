Número em reais que conta até o valor quando aparece ou muda, em IBM Plex Mono com algarismos de largura fixa.

**Use** para o valor principal de uma área (total do ano, total do mês) e em totais que mudam com uma ação, como na revisão.

**O consumidor fornece:** `value`; opcionalmente `prefix` (padrão `"R$ "`; use `""` para contagens), `decimals`, `duration` e `style` para tamanho e cor.

- Não anime números em tabelas ou listas longas: lá use o estilo `figure` estático.
- Com movimento reduzido no sistema, o número aparece direto, sem contar.
